CSS Box Model Exploration

Understand the four layers of the CSS box model.

The Four Layers

Margin
Border
Padding
Content

Content: The text, image, or other information inside an element.

Padding: The space between the content and the border.

Border: The line surrounding the content and padding.

Margin: The space outside the border that separates elements.

Box-Sizing Comparison

Default: content-box

Width: 200px

Padding and border are added to the specified width.

box-sizing: border-box

Width: 200px

Padding and border are included in the specified width.
