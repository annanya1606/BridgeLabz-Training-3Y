Responsive CSS Cheat Sheet

Quick Reference for Responsive Web Design

Filters

CSS filters can change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply different CSS styles based on screen size.

@media (max-width: 700px) { }

Responsive Design

Responsive design makes websites adapt to different devices.

width: 100%;

Typography

Responsive typography adjusts text size according to screen size.

font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

Flexbox is useful for arranging elements in rows or columns.

display: flex;

CSS Grid

Grid is useful for creating responsive rows and columns.

display: grid;
