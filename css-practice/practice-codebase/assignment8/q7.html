Responsive Design

Responsive web design allows a website to adjust its layout according to the screen size. Flexbox and Grid can be used to arrange elements, while media queries can change the layout on smaller screens. Relative units and responsive typography also help create a better experience on different devices.

CSS Cheat Sheet

Flexbox

Used for flexible row and column layouts.

Grid

Used for creating rows and columns.

Media Query

Changes styles based on screen size.

Clamp

Creates responsive font sizes.
